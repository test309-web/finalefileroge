
# 🎓 School Platform - Plateforme Éducative

## 📖 Description
Plateforme éducative complète développée avec **React.js** et **Laravel** permettant la gestion des leçons, exercices et suivi académique entre enseignants et étudiants.

## 🚀 Fonctionnalités Principales

### 👨‍🎓 Espace Étudiant
- 📚 Consultation des leçons et exercices
- 🔍 Recherche et filtrage avancé
- 📊 Suivi des points et progression
- 📱 Interface responsive adaptée mobile

### 👨‍🏫 Espace Enseignant
- ➕ Création et publication de leçons
- 📝 Gestion des exercices et évaluations
- 🎯 Attribution des points aux étudiants
- 📈 Tableau de bord statistiques

## 🛠️ Technologies Utilisées

### Frontend
- **React.js 18** - Interface utilisateur moderne
- **Bootstrap 5** - Design responsive
- **Axios** - Communication avec l'API
- **React Router** - Navigation entre pages

### Backend
- **Laravel 10** - Framework PHP robuste
- **MySQL** - Base de données relationnelle
- **Laravel Sanctum** - Authentification sécurisée
- **Swagger** - Documentation API automatique

## ⚙️ Installation et Démarrage

### Prérequis
- PHP 8.1+
- Composer
- Node.js 16+
- MySQL 5.7+

### Installation Backend
```bash
cd backend
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate
php artisan serve
```

Installation Frontend

```bash
cd frontend
npm install
npm start
```
